# BiBit User Guide

This guide is organized into a quick start guide and feature guides. Begin with [Quick Start](quickstart.md), or browse the topics below.

For local versus cloud processing and available device tools, see [Intent Recognition](modules/intent.md).

To manage Runtime experts, model services, capabilities, or security policies, or to view Runtime status, see [Runtime Management and Monitoring](modules/runtime.md).

For questions or feedback, contact the developer community. The documentation is updated regularly.
