# Quick Chat

This version of BiBit Desktop supports keyboard input in Quick Chat. Recording, voice wake-up, and speech recognition are unavailable.

## Open Quick Chat

Click the BiBit icon in the system tray or click the desktop floating icon once. To open the main window, double-click the floating icon or right-click the tray icon and choose **Open Main Window**.

## Send a Message

1. Check the conversation shown at the top of the window. Choose **New conversation** to start a fresh topic.
2. Type your message. Press **Shift+Enter** for a new line.
3. Press **Enter** or click the send button. Read the reply in Quick Chat, or click **Open main window** to view the full conversation.

## Switch Conversations

Use the conversation selector to choose a recent conversation or start a new one. If **Continue last** appears, use it to return to the previous conversation. Quick Chat and the main window share the active conversation. If BiBit warns about an unsent draft, an attachment in progress, or a running task, handle it before switching.

## Resize the Window

Under **Settings → General → Desktop Integration**, set the [Quick Chat window size](settings.md#resize-the-quick-chat-window). The supported width is **300–600** and height is **400–800**, in logical pixels (units that follow your display scaling).

## Pin the Window

**Pin window** keeps Quick Chat in front of other windows. It is separate from pinning a conversation in the sidebar.
