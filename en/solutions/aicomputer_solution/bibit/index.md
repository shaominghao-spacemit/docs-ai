# BiBit User Documentation

[简体中文](../../../../zh/solutions/aicomputer_solution/bibit/index.md) | [English](index.md)

[BiBit Introduction](introduction.md)

This guide is for Bianbu Desktop users who already have BiBit installed. If you have questions or suggestions, ask in the developer community. The documentation is updated regularly.

The interface and available features may vary by version or device. Follow the interface on your device.

If this is your first time using BiBit, start with [Quick Start](user_guide/quickstart.md).
