# 常见问题

先按下表排查；仍有问题时，可到开发者社区提问。

| 问题或提示 | 建议操作 |
| --- | --- |
| 窗口上方显示“连接失败” | 检查设备网络，点击旁边的重试连接按钮；仍失败时记录完整提示，到开发者社区提问 |
| “请选择助手”或没有可用专家 | 在新建聊天页打开专家列表，刷新后选择可用项；仍没有可用项时，可到开发者社区提问 |
| 助手提示“尚未选择全局模型” | 到 **设置 → 管理 → 模型列表** 添加一个模型并选为当前模型，再发送 Runtime 对话消息 |
| 发送按钮不可用 | 检查是否有文字或可发送附件、附件是否处理完毕、专家是否可用，并阅读输入区提示 |
| 回答一直没有变化 | 查看是否正在执行工具或等待权限确认；先检查状态和错误再决定停止或重试 |
| “上一次消息操作结果尚未确认” | 优先使用“重试原操作”或“原样重试”，或重新读取会话；不要立即重复提交同一项设备操作 |
| “会话读取已停止” | 使用“重试读取会话”；恢复前输入可能被禁用 |
| 找不到历史聊天 | 清除搜索条件；检查侧栏是否收起、服务是否已连接，以及当前服务目标是否发生变化 |
| 文件上传失败 | 读完整错误，检查文件是否存在、是否超限；重试或移除后重新选择 |
| 文件打不开或不能总结 | 确认文件仍存在，回到原会话，等当前回答结束；文件变化后重新搜索 |
| 截图入口不可用 | 确认当前桌面会话和截图工具可用，并在快捷键设置中检查状态；可先使用普通文件附件 |
| 全局快捷键无反应 | 确认“启用 BiBit”已开启，快捷键已注册，且没有被其他桌面快捷键占用 |
| 看不到悬浮球 | 右键托盘图标选择“显示/隐藏悬浮球”；必要时从应用菜单打开主窗口检查驻留设置 |
| 没有能力中心、记忆等入口 | 该设备可能没有启用对应插件；旧版 Agent Hub 的入口和操作也可能不同，可记录应用版本和当前界面，到开发者社区提问 |
| 设置里没有“管理”或“监控”分组 | 到 **设置 → 扩展** 检查 Runtime 管理扩展是否已安装并启用；安装或启用后按提示重启 BiBit |
| Runtime 页面显示“Runtime 不可用”或“宿主能力未提供” | 确认 Runtime 服务正在运行、插件授权有效；刷新后仍失败时记录完整提示，到开发者社区提问 |
| “测试连接”失败 | 核对供应商、API Base（通常以 `/v1` 结尾）和 API Key；私有网关要填实际可达地址。若提示“插件与 Runtime 协议不匹配”，先确认 Runtime 包与插件版本配套 |
| MCP 一直显示“准备中”或“失败” | 首次安装可能较慢，先等待并刷新；失败时查看卡片上的原因，检查启动命令、依赖和目录权限 |
| 安全页面显示“securityd 不可用” | 检查 Runtime 安全桥接和 securityd 状态；不要反复保存策略，先记录提示并刷新 |

## 如何向开发者社区提问

自行排查后仍不能解决时，可以到开发者社区提问，并附上以下信息：

1. 打开 **设置 → 通用 → 应用版本**，点击 **复制版本信息**。
2. 记录问题发生时间、当时所在的会话，以及点击了什么、期待什么、实际看见什么。
3. 复制完整错误文字；能用不含私人资料的简单问题复现时，同时说明复现步骤。
4. 需要附日志时，在通用设置的 **应用日志** 中使用打开或显示日志的入口，提供与问题相关的片段即可。

提交问题前检查日志或截图中的个人内容、文件路径、账号和密钥，只提供排查所需的信息。
