# BiBit 用户使用指南

本指南已按快速开始和功能模块整理。第一次使用请阅读[快速开始](quickstart.md)，也可按下方章节目录跳转。

想了解哪些请求在本地处理、哪些交给云端，以及可用的设备工具，请阅读[意图识别](modules/intent.md)。

想管理专家、模型、能力、安全策略或查看运行状态，请阅读[Runtime 管理与监控](modules/runtime.md)。

如有问题或改进建议，可到开发者社区反馈，文档会持续更新。
