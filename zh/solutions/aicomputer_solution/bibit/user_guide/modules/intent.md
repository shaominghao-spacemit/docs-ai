# 意图识别

使用 BiBit 时，你不需要记住工具名称或命令，可以直接说出想做的事。BiBit 会根据请求内容，优先在设备本地处理支持的明确操作；需要解释、创作、综合分析或理解复杂要求时，则交给云端助手。

本文帮助你了解哪些话适合本地处理、哪些通常需要云端，以及怎样表达更容易得到预期结果。

想查看具体有哪些工具及其用途，请参阅 [BiBit 本地工具列表](tools.md)。工具在设备上执行，不代表请求一定完全在本地理解；清单中也单独标明了需要联网或云端协调的扩展。

> 以下示例说明典型处理方式，实际结果视说法和功能状态而定。

## 1. 先记住这条区别

**明确地操作这台设备，通常优先本地处理；需要解释、分析、创作或安排复杂任务，通常交给云端。**

| 你说的话 | 通常如何处理 | 原因 |
| --- | --- | --- |
| “把音量设置为30%。” | 本地优先 | 操作和目标值明确 |
| “查看当前系统时间。” | 本地优先 | 查询设备已有的信息 |
| “打开浏览器。” | 本地优先 | 启动已安装的应用 |
| “为什么电脑没有声音？” | 云端 | 需要分析原因，而不只是调节音量 |
| “帮我写一份会议通知。” | 云端 | 需要生成文字 |
| “打开浏览器，搜索资料，再整理成报告。” | 云端 | 需要安排多个不同的步骤 |

云端可以帮助理解任务，再通过设备工具执行本机操作。

## 2. 哪些话适合在本地处理

### 2.1 调节音量和屏幕

尽量说清楚要调整什么，以及调整到多少。

| 想做什么 | 可以这样说 |
| --- | --- |
| 查询音量 | “查看当前音量。” |
| 设置音量 | “把音量设置为30%。” |
| 相对调节音量 | “把系统音量调大一点。” |
| 静音 | “静音。” |
| 恢复声音 | “取消静音。” |
| 查询亮度 | “查看当前屏幕亮度。” |
| 设置亮度 | “把屏幕亮度设置为60%。” |
| 查询显示模式 | “查看屏幕支持的显示模式。” |
| 设置分辨率 | “把屏幕分辨率设置为1920×1080。” |

屏幕亮度、分辨率等操作受设备和显示器支持情况限制，请查看实际执行结果。

“调到30%”与“调大一点”不是同一个意思。想要确定的最终音量时，建议直接说“设置为30%”。

### 2.2 打开应用、查看设备状态

| 想做什么 | 可以这样说 |
| --- | --- |
| 启动应用 | “打开浏览器。” |
| 关闭应用 | “关闭计算器。” |
| 查看系统信息 | “查看系统信息。” |
| 查看网络状态 | “查看有线网络状态。” |
| 查看设备地址 | “查看有线网络IP地址。” |
| 锁定屏幕 | “锁屏。” |

应用需要已经安装且能够被系统找到。找不到应用、存在多个候选或目标不明确时，可能需要补充信息或由云端继续处理。

### 2.3 查询和设置时间、语言与区域

| 想做什么 | 可以这样说 |
| --- | --- |
| 查询时间 | “查看当前系统时间。” |
| 只设置时间 | “把系统时间设置为15:30。” |
| 只设置日期 | “把系统日期设置为2026-11-03。” |
| 设置完整日期和时间 | “把系统时间设置为2026-11-03 15:30:00。” |
| 查询语言和区域 | “查看系统的语言与区域。” |
| 查看可选项 | “列出可用的语言和区域。” |
| 切换界面语言 | “把系统语言改成英文。” |
| 切换回中文 | “把系统语言改成简体中文。” |

请注意：

- 设置时间会修改真实系统时间，不是创建提醒或闹钟。请勿把表中的日期示例直接当作当前时间使用。
- 仅设置日期时保留执行时的时分秒；仅设置时间时保留执行时的日期。没有提供秒时按00秒处理，不会修改时区。
- 自动校时开启时，需要按界面提示确认是否关闭自动校时，之后才能继续修改。没有确认就不应继续设置。
- 不同入口的确认支持可能不同。已检查的 CLI 版本可能不显示确认提示，而是等待超时取消；没有看到确认入口时，不要把等待或回复结束当作修改成功，请取消等待，改用桌面中可见的确认入口或系统日期与时间设置。
- 系统界面语言目前支持简体中文和英文；区域选项取决于设备已安装的配置，建议先查询再选择。
- 语言和区域修改作用于系统全局，通常需要注销并重新登录后才能完整生效。请先保存正在编辑的内容。

### 2.4 查找文件、打开文件夹和设置壁纸

| 想做什么 | 可以这样说 |
| --- | --- |
| 查找本机文件 | “在本机查找会议纪要。” |
| 打开常用文件夹 | “打开下载文件夹。” |
| 设置指定壁纸 | “把 /home/bianbu/Pictures/wallpaper.jpg 设置为壁纸。” |

路径示例需要替换成你设备上实际存在的路径。

“查找本机文件”和“总结文件内容”是不同的请求：前者可以优先使用本地查找能力，后者通常需要云端理解和生成回答。

设置壁纸需要明确的本地图片路径。“换张壁纸”并不表示自动切到下一张，也不会自动从网上挑选或下载图片。缺少路径时，需要补充图片位置。

## 3. 哪些话通常交给云端

### 3.1 问知识、解释原因或寻求建议

- “什么是防火墙？”
- “为什么电脑没有声音？”
- “帮我分析网络变慢的原因。”
- “推荐一款适合这台设备的视频编辑软件。”
- “你能帮我做哪些事情？”

云端可能先查询本机信息，再提供建议或操作步骤。

### 3.2 写作、总结、翻译和编程

- “帮我写一份会议通知。”
- “总结这份文档的三个重点。”
- “把下面这段话翻译成英文。”
- “写一个整理照片的脚本。”

这些请求通常交给云端模型处理。涉及文件或截图时，请先检查是否包含不准备提交的敏感内容。

“这份文档”需要有明确来源：请上传对应附件、提供实际文件路径，或粘贴正文；翻译请求也需要提供原文。新会话不要假定会自动沿用其他会话的材料。如果回答引用了本次未提供的截图或文档，请先核对来源，不要把它当作对目标文档的总结。

### 3.3 网上搜索和复杂任务

- “上网搜索有关 RISC-V 的资料。”
- “查找资料，比较几个方案，再生成报告。”
- “电脑上的软件打不开，帮我找出原因并修好。”
- “如果网络正常，就下载文件，否则帮我检查网络。”

这类请求可能涉及多个操作、条件判断或不确定的处理方案，通常由云端协调。能否真正搜索、下载或修复，还取决于当前助手是否具有相应工具与权限。

并不是一句话里有多个项目就一定上云。系统已经支持的固定流程，以及部分可直接组合的只读查询，也可以在本地完成。

### 3.4 依赖前文、含义模糊或本地不支持的请求

- “把它关掉。”
- “恢复刚才那个设置。”
- “把时间改一下。”
- “打开那个软件。”

这些话可能缺少对象、目标值，或需要结合前文理解，通常会交给云端继续判断或追问。

没有提供足够信息时，助手仍然会追问你补充说明。

## 4. 同一个主题，为什么有时本地处理、有时上云

关键不只是提到了什么，还包括你希望 BiBit 做什么。

| 本地操作类请求 | 通常需要云端的请求 | 区别 |
| --- | --- | --- |
| “把音量设置为30%。” | “为什么没有声音？” | 直接设置与分析原因 |
| “查看当前系统时间。” | “解释一下时区是怎么回事。” | 读取设备信息与知识解释 |
| “打开浏览器。” | “打开浏览器，查资料并写报告。” | 单个操作与复杂任务 |
| “在本机查找会议纪要。” | “总结会议纪要并列出待办事项。” | 查找文件与理解内容 |
| “把系统语言改成英文。” | “英文和中文界面各有什么优缺点？” | 修改设置与比较建议 |

当前实现会把“你能打开浏览器吗？”按礼貌的执行请求处理，并直接启动浏览器；问号不表示“只咨询、不执行”。只想了解功能时，请明确说明“只介绍功能，不要执行操作”；想让 BiBit 操作时，直接说明动作和对象更合适。

## 5. 怎样说更容易得到预期结果

1. **说明动作和对象。** 用“把系统音量调大一点”，而不是单独说“大一点”。
2. **能给明确数值就给明确数值。** 用“亮度设置为60%”，而不是“调到合适的亮度”。
3. **路径、应用名和目标要具体。** 用实际图片路径、明确的应用名称，减少“它”“那个”等指代。
4. **多个不同任务可以分开发送。** 先说“打开浏览器”，再提出搜索要求，有助于分别确认执行结果；搜索和生成报告仍可能需要云端。
5. **复杂任务不必强行拆成本地命令。** 可以直接描述完整目标，让云端协调；遇到确认或补充信息时再回应。
6. **不要用重复发送代替查看结果。** 操作还在执行、等待授权或结果不明时，先查看提示，避免重复操作。

## 6. 确认、权限和执行结果

需要确认的操作，无论在本地还是云端处理，BiBit 都会请你确认。

- 修改系统设置、关闭应用等操作可能影响正在进行的工作，请先保存文件。
- 需要权限时，根据可信的系统授权窗口输入密码，不要把密码发送到聊天消息中。
- 出现确认按钮时，先看清具体操作和目标，再决定是否继续。
- 如果显示取消、权限不足、超时或执行失败，不要认为操作已经完成；结果不明确时先查询实际状态。
- 某些操作本身就需要较长时间，等待不一定是意图识别或云端响应慢。

### 已知限制与结果核对

以下情况在部分版本中可能出现：

- **“✓ 已完成”不能单独作为成功依据。** 工具失败或未完成时也可能显示这行文字，请以设备实际状态为准。
- **句末标点不会影响已验证的本地查询和相对调节路由。** “查看当前音量。”、“查看当前屏幕亮度。”、“把系统音量调大一点。”和“把屏幕亮度调高一点。”均可以在当前设备上正确识别。中文或英文句末的 `。`、`.`、`！`、`!`、`？`、`?` 都可以保留；如果实际结果异常，请保留原句和标点反馈。
- **只完成一步不等于完成整个任务。** 追问后续步骤，直到看到最终结果。
- **启动检测可能滞后。** 如果提示未检测到应用，但窗口已经打开，先检查桌面，不要连续重复启动。
- **查询结果可能包含技术详情。** 语言与区域查询中的配置字段不是要求你手动修改的内容；若正文被截断或看不懂，可在系统设置中核对并反馈，勿根据残缺内容修改配置。
- **网络诊断超时不是故障结论。** 路由跟踪未完成不能单独证明网络中断或定位网速变慢的原因。如果整轮诊断失败，保留已显示的结果和错误提示；没有展示的步骤不能视为已完成。

## 7. 常见问题

### 本地处理是否意味着断网也能用？

部分设备控制可以在本地服务正常时离线使用，但不能把“本地优先”理解为所有功能都保证离线可用。功能还可能依赖已安装的模型、设备服务或网络资源；云端理解和网上搜索需要相应的网络与服务连接。

### 上云后，电脑上的操作在哪里执行？

云端负责理解或安排任务，需要操作这台设备时，仍通过本机工具执行，并受本机权限和确认机制约束。

### 本地请求是否保证任何信息都不会上传？

不能仅凭请求属于本地操作，就推断整段会话完全不会发送到云端。本地分流说明的是请求的处理方式，不是整个产品的数据传输保证。云端请求可能涉及消息、附件或为完成任务提供的设备信息，具体以当前版本的隐私说明和服务配置为准。

### 没识别出来时怎么办？

先把请求改成“明确动作 + 明确对象 + 必要参数”。例如，把“调一下”改成“把系统音量设置为30%”。如果仍然失败，保留原始说法和界面提示反馈问题，不要反复发送可能改变系统状态的操作。

### 交给云端后是不是一定能完成？

不是。云端也受到工具、权限、网络和设备条件限制。不能执行时，应根据提示补充信息、授权或改用手动操作，而不是把生成的文字当成操作成功的证明。
